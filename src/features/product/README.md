# Storefront: Product Detail Feature

## Purpose
The sensory centerpiece of the boutique. Presents flacon zoom photography, video campaign reels, interactive Olfactory Pyramid (Top, Heart, Base notes), volume size picker (50ml, 100ml, Discovery Set), formulation details, verified client reviews, and direct acquisition.

## Database Tables
- `products`
- `product_images`
- `product_videos`
- `reviews`
- `wishlist`
