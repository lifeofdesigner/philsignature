# Service Layer Specifications

## Service Contracts
- **`ProductService`**: Validates fragrance inputs, calculates sale discounts, builds search filters, and coordinates image gallery attachments.
- **`OrderService`**: Validates items, checks inventory, applies coupon logic, calculates delivery fee, and triggers order number generation.
- **`CategoryService`**: Validates category hierarchy and slug generation.
- **`CMSService`**: Manages site identity, hero sections, and announcement banners with auto-save support.
- **`UserService`**: Handles customer profile updates, address defaults, and role verification.
