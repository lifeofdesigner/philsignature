# API & Data Contracts

## Communication Flow
1. **Client -> Supabase**: RESTful HTTP queries generated by `@supabase/supabase-js` under PostgREST.
2. **Data Typing**: All data structures strictly typed using TypeScript domain interfaces (`src/types/database.ts`).
3. **Payload Sanitization**: Inbound inputs validated using Zod schemas before being dispatched to services/repositories.
4. **Error Payloads**: Normalized through `AppError` and `SupabaseError` classes.
