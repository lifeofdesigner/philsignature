# Phase 8: Visual Admin CMS, Media Library, Marketing & Store Settings

## Objective
Provide intuitive visual content management tools for all store sections (Hero, About, FAQ, Footer, Announcements), Supabase Storage media management, coupon creation, review moderation, and store-wide settings.

## Key Deliverables
1. **Visual CMS Manager (NO JSON)**:
   - Dedicated visual form sections:
     * Site Identity & Announcement Bar (Color picker, text, link, toggle).
     * Homepage Hero & Banners (Headings, CTA buttons, background media, overlay opacity).
     * Brand Story / About Page (Mission, Vision, artisanal ethos, banner uploads).
     * FAQ Manager (Add, edit, reorder questions & answers).
     * Footer & Social Links (Newsletter copy, Instagram, TikTok, WhatsApp links).
   - Live visual preview and auto-save / publish workflow.
2. **Media Library**: Supabase Storage explorer with folder categorization (Products, Banners, Collections, Logos), drag-and-drop file upload, file details, and instant copy URL.
3. **Coupons Engine**: Form to configure discount percentage or fixed amount, minimum spend, expiry date, and usage limits.
4. **Reviews Moderation**: Approve, Reject, and Feature customer reviews.
5. **Payments & Shipping Rules**:
   - Enable/disable Paystack, Flutterwave, Bank Transfer (with bank details), and Cash on Delivery.
   - Configure shipping methods and nationwide rates.
6. **Store Settings & SEO**:
   - Store name, email, WhatsApp concierge, currency, tax rates, timezone.
   - Global SEO, meta tags, Google Analytics and Facebook Pixel inputs.
