# Phase 6: Customer Account Portal & Printable Luxury Invoices

## Objective
Provide a refined, members-only customer experience for order history, real-time shipment status, printable luxury PDF invoices, address book management, wishlist, and profile settings.

## Key Deliverables
1. **Account Overview**: Recent orders, default delivery address, wishlist quick-view, spend summary.
2. **Orders History**:
   - Filterable order list with status badges.
   - Comprehensive Order Detail view with line items, price breakdowns, and shipment timeline.
3. **Printable Luxury Invoice**:
   - Haute couture styled invoice layout with PHILZ SIGNATURE gold crest, boutique details, customer snapshot, and printable CSS styling (`window.print()`).
4. **Saved Addresses**: Add, edit, remove, and set default shipping addresses.
5. **Wishlist**: Saved fragrances with direct one-click add to cart.
6. **Profile & Security**: Update contact info, change password, notification preferences.
