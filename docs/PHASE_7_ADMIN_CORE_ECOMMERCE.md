# Phase 7: Shopify-Grade Admin CMS Core (Products, Orders, Customers, Inventory)

## Objective
Deliver a first-class admin workspace with zero JSON exposure, providing visual forms, rich data tables, bulk operations, and inventory management.

## Key Deliverables
1. **Admin Layout & Navigation**: Responsive sidebar with all 16 planned ecommerce modules, quick search, notification feed, and user profile badge.
2. **Analytics Dashboard**: Live revenue metrics, total orders, average order value, conversion trends, low-stock inventory alerts, and recent order stream.
3. **Products Module**:
   - TanStack Table with search, category/status filters, pagination, and CSV export.
   - Comprehensive Product Form:
     * Basic info (Name, Slug, SKU, Barcode, Weight).
     * Financials (Price, Sale Price, Stock Quantity).
     * Formulations & Categorization (Category, Collection, Fragrance Family).
     * Visual Olfactory Pyramid Builder (interactive tags for Top, Heart, Base notes).
     * Multi-image gallery uploader and video embed link.
     * Marketing badges (Featured, Bestseller, New Arrival, Trending).
     * Dedicated SEO metadata card with live Google preview.
   - Product Duplicate and Archive capabilities.
4. **Collections & Categories Modules**: Full visual CRUD for fragrance groupings and banners.
5. **Orders Management**:
   - Filter by payment status and fulfillment status.
   - Order detail drawer/page with customer details, order timeline updater, tracking number assignment, and one-click invoice generation.
6. **Customers Directory**: Lifetime spend calculations, total orders, and order history view.
